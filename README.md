# humboldt

Humboldt squid hunt fish in packs. This one hunts phish.

A local, human-in-the-loop tool for reporting scam and phishing links that arrive
over chat apps (Telegram, WhatsApp, SMS). Paste the message; humboldt finds who can
take the link down and files or drafts the reports.

Status: design. See [`docs/design.md`](docs/design.md).
